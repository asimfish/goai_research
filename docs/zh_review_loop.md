# 中文报告排版的并行多代理审查环（2026-09-13）

用户要求“好好调整下我们的并行多 agent loop 系统”后固定下来的流程。目的：不再靠单人肉眼抽查，而是每次构建后由多个审稿代理并行逐页审查，汇总缺陷、修 sty/章节、重建，直到无 P0/P1。

## 环
1. **构建**：5090 docker（`build_v3.sh`），要求 0 错误、0 Overfull（日志 grep）。
2. **渲染**：`tools/zh_render_pages.sh <pdf> <outdir> 100` → 逐页 PNG。
3. **并行审查**：按页分给 3–4 个审稿代理（每人 ≤ 12 页），提示词 = `templates/zh_layout_checklist.md` + 页面路径 + 只读的 sty/章节/bib 路径；输出统一格式 `P0/P1/P2 | 页 | 元素 | 缺陷 | 期望 | 修法`。代理只报不改。
4. **汇总与修复**：主控合并三份清单，按 sty（全局）→ 生成脚本（表格）→ 章节（局部）的顺序修；每项修复记录在 `docs/zh_typesetting_v3.md`。
5. **重建 + 复审**：改动页重新渲染，由一名复审代理确认已修复项并检查回归；无 P0/P1 后部署。
6. **门禁**：`tools/zh_qa.py`（引用/公式/数字/表格结构不变）必须 PASS；改样式不得改内容。

## 分工建议
- 审稿 A：首页、摘要、前 1/3 页面（标题块、标题层级、图）。
- 审稿 B：中间页面（长表、续表、分区行、表头）。
- 审稿 C：末 1/3 + 参考文献（条目格式、DOI 断行、缺陷条目）。
- 复审 D：只看改动页 + 随机 3 页回归。

## 历史教训（来自本轮）
- 长表题注需与前文分开（LTpre 14pt）、小号字 + 粗体标签；否则与正文粘连。
- 横排页对该用户不可接受；宽表拆成两张竖排长表（编号对应）。
- 表列宽用版心比例，Σ=1；不要用固定厘米。
- 引用保持蓝色（用户明确要求）。

## 第一轮记录（2026-09-13，NeurIPS 版式 v5）
三名审稿代理并行（BYZSO 1–12 页 / 13–24 页 / BaZn2Si2O7 8 页），共 64 条：P0 7 条、P1 34 条、P2 23 条。按来源归类后的修法：
- 样式层（sty）：`\raggedbottom` 替代 NeurIPS 的 `\flushbottom`（中文段间 5.5pt 刚性，短页被撑开）；标题 `\boldmath` + 行距 1.15；run-in 标题前 1.0ex 后 0.5em；表格 `arraystretch` 1.2；题注 `stretch=1.15`；`url[hyphens]` + `\urlstyle{same}` + 只在 / - _ ( ) 断行；自定义 `\doi` 为蓝色链接；`\bibsep` 加弹性、参考文献禁连字；en dash（U+2013）声明为西文字符类，避免其后空格被吞。
- 生成脚本（zh_table_merge.py）：分区行 `\\*` 禁止其后分页；长表 8pt/3pt/1.05；续表题注“续表”。
- 章节层（脚本批量）：`\ref{}` 后补 `\CJKecglue{}`（hyperref 链接末尾会阻断 xeCJK 中西文间距）；行首 `\textbf{…。}` 统一为 `\paragraph`；西文复合词 `A/B/C` 改 `\slash`；`$M=$Co` → `$M$ = Co`；公式中变量 x 用 `\mathit{x}`；表头显式换行；表列宽微调；bzso 三张表补 `\label` 与正文引用。
- 参考文献（tools/bib_polish.py）：化学式/元素符号/缩写/希腊字母整词加花括号防小写化；名字连字与“姓, 名”修正（Zhao Zi-Long、Zhang Shoudu…）；学位论文/数据集改 `@phdthesis`/`@misc`；删除 ChemInform 重复条目；Crossref 按 DOI 补 volume/number/pages（BYZSO 125 项、BaZn2Si2O7 75 项）。
- 不能在 LaTeX 层解决、留给图件流程：三张 drawio 图内文字缩放后仅 ≈4pt、图内自带标题/图例与题注重复、Type 3 字体。

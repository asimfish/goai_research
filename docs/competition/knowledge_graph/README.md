# SAGE-Mat 知识森林（知识图谱展示）

把一次调研画成一棵树的年轮：中心是研究者开始前的调研主题，向外每一圈是一层生长（个人知识树 → 文献树 →
实体主干 → 结论树 → 长出的新树），文献树的八个分支把圆盘分成八个扇区，同一扇区里的叶节点、文献、实体、
主张、新树在径向上对齐；跨层连线沿层级束化，跨扇区的连线绕内环走，中心始终留给根与五个目标。
视觉语言与看板站点、答辩 PPT、宣传封面同一套：浅灰蓝底、白卡片、青 + 橙强调、Chakra Petch，以及 PPT 的化学插画（中心是研究者，八个扇区与五棵新树各一枚图标）。只给关键节点常显标签，放大后再显示其余标签。页面是单文件 HTML，数据全部从提交包里
已有的文件确定性生成，不新增任何主张。

## 五层怎么长

| 层 | 节点 | 来源文件 |
|---|---|---|
| 0 个人知识树 | 调研主题 → 5 个预期目标（核心问题）→ 8 个 MECE 子主题 | 正式案例 `inputs/topic.md`、`inputs/scope.md` |
| 1 文献树 | 8 个分支 → 35 个叶节点 → 51 篇通过 ref_gate 的文献；按 D0 / D1 / N1 / P1 / X 证据距离着色，外圈加深 = 全文在证据包内 | 证据包 `notes/taxonomy.md`、`references.bib`、`papers.jsonl`、`claim_evidence_summary.json` |
| 2 实体主干 | 12 个元素（目标相的 Ba/Y/Zn/Si/O 深底；替代 / 助熔 / 对照元素浅底）→ 29 个化合物 / 相（含有元素的连线由化学式解析）→ 6 条合成路线（含水热空白）→ 29 条逐字段的合成条件记录（A1、B1–B6、C1–C22）；另有 17 种前驱体 / 助熔剂 / 坩埚、7 类表征终点、4 类失败模式 | 正式案例 `最终输出/sections/03_condition_matrix.tex` 条件总表；`taxonomy.md` §A–§G；元素角色、化合物与试剂为人工整理表（脚本内 `CURATED_*`） |
| 3 结论树 | 27 个章节 → 100 条主张；每条主张回连引用文献（强 / 弱、全文、条件溯源）与提到的实体；章节回答第 0 层的目标（已回答 / 部分回答） | 证据包 `claim_evidence.jsonl`；目标 ↔ 章节的对应是人工读稿给出的（脚本内 `Q_MAP`） |

## 连线是怎么算出来的

- 结构线（默认显示）：树的父子、文献 → 叶节点（taxonomy 的支撑 key）、文献 → 条件记录（表格里的 `\texttt{key}`）、条件记录 → 产物 / 路线、章节 → 目标、根 → 新树、新树 → 相关实体。
- 引用线：主张 → 文献来自 `claim_evidence.jsonl` 的 `citation_keys`；主张 → 条件记录来自 `condition_source_trace`。
- 文本匹配线（勾选「全部连线」或悬停时显示）：文献题名 / 条件记录产物字段 / 主张文本里出现化合物别名 → 化合物；条件记录原料与坩埚字段 → 前驱体 / 坩埚；产物与表征字段 → 表征终点。别名表在脚本里，逐条可审。
- 文献的证据等级 = 它支撑的叶节点标题里的等级（如 A2（D1））；叶节点没标等级时取题名里报道的化合物等级；再没有取叶名里写明的等级；否则记 X。

## 视觉约定（站点浅色语言，底 `#F1F4F7`；三个强调色在浅底上经 dataviz 校验两两可分辨，含色觉缺陷模拟）

- 橙 `#E06A1B` = 目标相谱系（D0 目标相直接证据：深色环 + 放大 + 常显标签；D1 同一身份谱系用浅橙 `#F3A56E`）。
- 青 `#1E8FA8` = N1 晶体化学近邻，也是分支、路线、目标编号的结构色。P1 工艺近邻、X 边界用中性灰阶（`#8A97A5` / `#C5CED8`），不占色相。
- 紫 `#7A4FD6` = AI 推断 / 模型预测（RECIPE 前驱体组合、实验方向、Mg / Co 假设目标、Zn–Y–O 电荷平衡系列），虚线轮廓，全部未经实验验证，节点详情里写明 `chemical_route_verified=false`。
- 状态色：红 `#C93D2C` = 失败模式（实心）与证据缺口（虚线）；绿 `#1F9D62` = 目标已回答；深青 `#156082` = 自动化工作流（仿真）。
- 节点：结构类为白底描边圆，文献 / 主张为实心点，外加 2px 白色分隔环；连线为细墨线（multiply，透明度 0.2 以下），颜色跟随文献 / 化合物的证据等级，悬停或点击时相邻连线点亮。
- 插画：`docs/competition/deck_figures/art/` 的化学图标由 `build_graph.py` 缩到 176px 后以 data URI 嵌入：中心 researcher，扇区 A–H = structure / phasediagram / precursors / furnace / condtable / xrd / guard / route，新树 = recipe / plan / robotlab / search / litdb。
- 标签策略（一帧海报约 40 个可读标签）：根（圆内两行）、目标（圆内 Q1–Q5 + 沿环弧形短标签）、路线（按角度上下交替）、目标相元素、D0 与假设目标化合物、失败模式、新树根（沿环弧形标签）及其子节点（最外圈，沿半径放射，22px）常显；分支节点只有字母，分支名是外圈扇区弧上的 30px 弧形文字；文献、化合物、叶节点、分支名等在放大到 1.5× 后显示；主张编号 2.6× 后显示。
- 布局参数在模板里：`RG`（各圈半径与节点间距）、`HUB`（跨扇区连线绕行的内环半径）、`STAGE_R`（五圈年轮半径）、`sectorOf()`（节点归属扇区）。

## 边界

- 图里所有数字（51 / 219 / 100 / 54 / 36 / 29）与证据包一致；RECIPE 预测全部为 `chemical_route_verified=false`，工作流全部为仿真，页面上都有标注。
- 目标 3、4 标为「部分回答」，理由写在节点详情里（目标相本身条件字段全为 NA；Zn 固溶范围没有直接证据）。
- 与文献的连线只在页面里展示，不回写任何提交材料。

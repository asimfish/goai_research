## 构建两个前端

Node 24.19.0、pnpm 10.30.3 已验证。现有源码适配按以下相邻目录布局工作；请在空目录中执行：

```bash
git clone --branch feat/materials-console-20260918 \
  https://github.com/asimfish/goai_research.git goai_research
git clone --branch feat/materials-evidence-workbench \
  https://github.com/Xuwznln/OpenLabSite.git goai_final_lab/src/OpenLabSite
git -C goai_final_lab/src/OpenLabSite checkout cae2f43d7f9999c651ffc4a69a7a04aea557c08c

cd goai_final_lab/src/OpenLabSite
pnpm install --frozen-lockfile
pnpm run app:build
cd ../../../goai_research/tools/console
pnpm install --frozen-lockfile
pnpm run build
```

循证台 `@materials` 指向相邻 OpenLabSite 的 `src/`；安装两个项目的锁定依赖后即可构建。循证台可发布文件在 `tools/console/dist/`，已随本次提交更新。OpenLabSite 构建产物不入其仓库，可在本地重新生成。

5051 材料部署使用现有网关和 `dist-materials/`。此目录包含历次在线哈希资源，作为部署目录忽略，不把旧版本缓存全部提交到 Git。

仅构建前端不会安装 UniLabOS、材料执行桥、驱动、实验数据库或模型资产。实际运行继续使用已配置的配套服务；端口转发、环境与运行方法见 [材料循证台操作手册](材料循证台操作手册.md)。研究控制台独立启动方法仍见主 README。

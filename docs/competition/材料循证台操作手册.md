## 1. 入口与运行方式

- 循证台：**http://127.0.0.1:5051/#/experiments**。
- OpenLabSite 材料版：http://127.0.0.1:5051/openlab/#/materials。
- 费用：http://127.0.0.1:5051/#/costs；本轮真实 Luna 记录可选择“材料循证台工作流验收”。
- 研究统一显示固定编号 `R-工作区ID`，例如 `R-F7D0BA2E37`；编号在研究列表、运行、结果预览、首页和费用页面一致。费用选择器同时显示创建日期和时间，可按主题、编号或日期搜索。
- 研究、历史和结果沿用原循证台导航，原 17 个工作区保留，新增本次工作流验收工作区。

远程只需转发本机 **5051**。浏览器页面、研究 API、Edge HTTP/MCP/SSE、仿真命令、状态 WS 和模型均经此端口；无需暴露 8002、8090、8091、8093。开发页面也配置了同源代理。

### 页面导航（2026-09-18 更新）

- **角色与技能**：左侧分组下常驻展开“角色总览 / 技能 / 工具”。技能页只展示角色技能索引和规程正文；工具页独立展示 MCP 服务，可搜索服务或工具名称，点击工具查看参数。角色详情页切入技能时会打开对应角色的规程。
- **研究工作台**：左侧分组下常驻展开“发起研究 / 运行过程 / 实验执行 / 费用”。查看指定研究后切去实验或费用再回来，会保留刚才的运行记录。
- **结果预览**：查看研究交付物，地址仍为 `#/results`。

“费用”位于左侧研究工作台的第四个子菜单，默认按创建时间选择最新研究，不再先加载全部研究汇总。选择器保留研究编号、时间和主题，最新一项有“最新”标记；仍可手动选择其他研究或全部研究。从某次运行点“算力 / 费用”会直接显示该次研究。

侧栏按“角色与技能 / 研究工作台 / 结果预览”分组，宽度为 80px，保留完整文字和图标。两组二级菜单始终展开，切到结果预览或设置页面也不会隐藏。当前页面在对应子菜单高亮；窗口较矮时菜单区独立滚动，底部设置入口保持可用。原顶部二级页签栏已移除。

各页标题与主要操作统一放在全局顶部栏，右侧保留服务与登录状态，内容区不再重复栏目标题。实验页“材料实验工作台”与“配方与记录 / 新建实验规划 / 动作演示 / 回放上次实验”位于顶部同一行；选中方案的名称在下方放大显示。费用页的“刷新 / 导出 JSON”也在顶部。原生 OpenLab 材料页保留自己的标题区。

页面占满浏览器可用高度，文档本身不滚动。技能索引、技能正文与目录在各自区域内滚动；工具服务以等高的 2×2 卡片排列，展开详情时只滚动该卡片。结果预览的历史研究、中央 PDF 与右侧交付清单分别在固定高度内滚动。滚动条统一使用细的灰绿色圆角滑块，去掉箭头。研究和结果页面的检查标题统一为“结果质量检查”。

界面字体统一为无衬线字体：标题、正文、标签、数据、表单及弹窗共用一份字体配置，层级通过字号与粗细区分。本机采用 Noto Sans CJK SC；其他浏览器依次使用同类中文系统字体。实验参数和共享 OpenLab 组件在循证台内也使用此配置。

费用页顶部展示已计金额、对话次数、回复条数、MCP 调用和用量回执。对话按已记录的模型线程去重；回复只计已完成的模型消息，含过程说明和最终答复，不含推理、工具返回或流式片段。无消息日志时显示“—”。例如 `R-A1C302457C` 有 1 次对话、7 条回复、12 次 MCP 调用，已计金额 USD 0.02270264；当前价格配置折算，计价口径与原金额不变。详情见 [费用说明](../USAGE_COST.md)。

原有 `#/roles`、`#/skills`、`#/history`、`#/run/<id>`、`#/experiments`、`#/costs` 地址继续有效，工具页新增 `#/tools`。研究推进使用浅色阶段卡片，逐项展示状态和负责人；并行阶段有文字标记，悬停可查看检查结果。

发起研究页的语料开关简写为“接入个人 PDF 语料库”；尚未配置时显示“尚未接入”并禁用开关。开始按钮上方的研究阶段、结果质量检查、模型、过程回放四项说明以 2×2 排列。左侧表单和右侧最近运行列表分别在面板内滚动。

运行过程的批次时间线从最早任务开始显示到最后任务结束，只有进行中的任务继续延伸到当前时间。已结束的任务不会因几天后查看而拉长横轴；切换批次后按当前范围重新计算。缺少结束记录时使用最后活动或已记录耗时，不附加空闲时间。例如 `R-F7D0BA2E37` 的 40 个任务对应 6 小时 8 分，而不是延伸至查看当天。

角色卡片超出可视宽度时，下方显示细的灰绿色横向滚动条。拖动滑块可查看后面的角色；底槽透明，悬停时滑块加深。

本轮执行方式是**网页轨迹仿真**：UniLabOS 确实调度外部模拟设备，Three.js 确实执行并检查最后一帧，驱动等待回执后返回。使用 Isaac USD 导出的真实几何，但本轮视频没有运行 Isaac 接触物理。旧 8090 查看器、8091 Isaac 桥和 5180 旧 OpenLab 留作历史，不能与新入口混称。

## 2. 运行一次实验

1. 打开实验页，等待模型加载完成与“UniLabOS 已连接”。首次进入这个 origin 需缓存约 101 MB 主 GLB；以后哈希相同直接使用缓存。旧 8090 的浏览器存储不与 5051 自动共享。
2. 点右上角“新建实验规划”，在左侧“配方”标签选择 MgO 或 MgCO₃ 独立对照。窗口较窄或侧栏收起时，先点顶部“配方与记录”。两者来自现有 AI 研究，组成和原料来源可展开核对；其他尚未绑定的研究保留在研究目录。每次提交会创建独立记录，旧实验不会覆盖当前规划。
3. 在“实验方案”查看来源、用量、热程序与表征；“调整参数”复用 OpenLabSite 参数表单，提交前由后端校验。修改只影响本次实例，不覆盖源研究。
4. “工作流”显示 7 阶段、73 个原子节点。规划中点击节点，下方控制区显示该步名称、工艺耗时与“未执行”；历史记录中点击已执行节点，会读取原始轨迹并暂停在该动作起点，场景、右侧选中项与底部回放同步。查看该步设备、参数和返回结果可展开上方详情。运行后可打开原生任务图。
5. 默认 1×。可选 10、50、100、300、600、1200、3600×；只有一个服务端仿真时钟，网页与驱动不重复乘倍速。演示推荐搬运 10×、加热与冷却 600×。
6. 点“提交运行”。也可用运行按钮下拉选择“逐步执行”，每次“执行下一步”只放行一个 UniLabOS 节点；“转为自动”调用正式任务控制接口。
7. 机械臂、夹爪、导轨、抓取物、四坩埚整盘和炉门同步。默认隐藏天花板。“跟随流程”按站点切镜；手动拖动视角后不会被自动镜头抢回。
8. 完成后手动切换“结果”查看执行情况；页面不会在轮询时切换你选择的标签。左侧切换“执行记录”标签，再点“查看记录”在本页查看历史结果；结果区域可另开 OpenLab 原生任务记录。轨迹记录和结果回读均有 run/task/job ID。

### 场景与控制区

- 电脑窗口中，场景随可用高度调整，倍速、提交和播放控制保留在场景下方。右侧方案或动作列表独立滚动。
- 左侧“配方 / 执行记录”分为两个标签。顶部“收起配方与记录”可给场景留出更大宽度；窄窗口自动收起此栏，再打开时以浮层显示。
- 场景右上方“专注场景”收起两侧面板，“退出专注”恢复。切换保留当前视角、动作和三维画布，不重新读取模型。
- “全景 / A 制备 / B 热处理 / C 表征 / 跟随流程”位于画面右上角。回放时可在下方拖动播放进度或逐个动作检查。场景页脚不再显示坐标轴提示，选中对象的实际坐标仍可查看。

### 回放与复用历史配方

1. “回放上次实验”打开最近一条包含已完成动作轨迹的记录；也可在左侧指定某条记录并点“回放过程”。读取期间，遮罩覆盖整个实验工作台，显示正在读取的轨迹数量，完成后解除；错误时显示原因。第一步就失败、尚无已完成轨迹的记录会显示“暂无轨迹”。
2. 回放支持暂停、继续、从头播放和倍速。拖动进度条会暂停并同步右侧动作、场景状态和下方名称；点击已执行的工作流动作会暂停在该动作开始，支持向前或向后跳转。同一页再次打开已读取记录时复用轨迹缓存。
3. 完整回放保留全部 73 个工作流节点，包括部分失败记录中的未执行步骤。点击未执行步骤，下方显示动作名称和“未执行”，场景保留最后已记录状态，进度条停在已记录轨迹末尾。回放只读取保存的轨迹，不重新提交工作流，不向驱动发送完成回执。实验正在执行时，点击节点只查看该步信息，不改变设备执行顺序。
4. 点“复用此配方”把该记录的投料与工艺参数带入新规划，调整参数后再提交；不会修改原记录。

当平台端口转发无法建立 WebSocket 时，页面自动通过同源 HTTP 同步状态。场景及执行连接就绪后才开放提交；无法提交时，悬停运行按钮可查看场景加载、状态连接或其他页面占用执行权等原因。

“暂停/继续”冻结与恢复当前仿真时钟。“停止”会阻断动作并使正式任务失败收尾：**0.12.3 没有公开的任务 cancel 接口**，因此不伪造 cancelled。逐步模式下停止会通过正式 resume 让下一驱动先触发停止检查，不生成下一轨迹，再按 Host 提供的 abort 选项释放任务资源。

同一时间只有一个浏览器拥有执行租约；其他标签为观察者。刷新会恢复同一命令，租约过期后可由另一标签接管。所有执行页关闭后时钟冻结；超过 120 秒正式失败，无后续动作。终点到达后 30 秒未收到合法末帧回执也会失败。失败任务保留证据；修复后新建一轮，不自动从失败步骤假装续跑。

### 动作演示：快速检查机械臂

1. 打开实验页，选择配方，等待场景加载完成，点右上角 **“动作演示”**。默认优先采用该配方最近一次完整执行记录；查看某条历史记录时，演示该条记录。
2. 完整记录的 73 步筛为 **23 个主要动作**：19 次机械臂搬运（包含夹爪和抓取物运动）、2 次导轨移动、2 次整盘装卸。开盖、称量、研磨、加热、冷却、检测等其余 50 步不播放。
3. 默认 **10×**，614 秒动作轨迹约 **61.4 秒**播放完。可选 0.5、1、2、5、10、20、50×；支持暂停、继续、上一动作、下一动作、从头播放，也可点击右侧动作或拖动进度条定位。右侧编号是本次播放序号。
4. **“主要动作 / 完整回放”**可随时切换，每次切换从头开始。同一记录的轨迹在本页内复用，切换不重新下载。刷新页面后重新读取轨迹；原有 GLB 持久缓存继续生效。
5. 被跳过步骤的状态仍会在下一段动作开始前恢复，例如炉门开关、托盘装样与样品位置。因此快进和后退均从原始记录恢复，不会依赖当前画面残留的状态。演示结束停在最后一个保留动作的末帧。
6. 演示播放已保存的轨迹，不创建实验、不调用设备执行、不提交驱动完成回执；实验原始 73 步与执行证据保持不变。部分完成的记录只包含已完成的机械臂动作，页面会标明“部分记录”。尚无轨迹的配方需先执行一次实验。

此模式适合检查搬运路径与录屏。要运行修改参数后的新实验，使用“新建实验规划 → 调整参数 → 提交运行”。

## 3. 固定模板与科学边界

模板 `solid-state-four-precursors/1.0.0`，拓扑 SHA256：

```text
301e2d53e4ed02cead0beb44cae8579811216c54369afd59e569acdef4f05ef1
```

| 参数 | MgO 对照 | MgCO₃ 对照 |
| --- | ---: | ---: |
| BaCO₃ | 0.986675 g | 0.986675 g |
| Y₂O₃ | 1.35486 g | 1.35486 g |
| SiO₂ | 0.4806744 g | 0.4806744 g |
| 第四前驱体 | MgO 0.040304 g | MgCO₃ 0.084313 g |
| 工程热程序 | 2 °C/min 至 300 °C，再 15 °C/min 至 1000 °C，保温 240 min | 相同 |
| 目标表达式 | Ba₅Y₁₂MgSi₈O₄₀ | 相同 |

路线：核对 → 四种原料逐一取瓶/开盖/去皮/投料/称量/关盖/归位 → 混合与装坩埚 → 清空托盘目标槽并装样 → 导轨、开炉、整盘入炉 → 加热/冷却 → 整盘出炉/台面冷却 → 回收/封盖/振摇 → XRD 制样/入腔/扫描/归位 → 归档与复位。

此工艺名义时长 **33,126.187714 s（9 小时 12 分 6 秒）**。冷却使用未标定的指数模型。用量按 1 mmol 目标式工程记账计算；升温、保温、冷却、研磨和扫描参数来自既有仿真模板，均标注 `simulation_assumption`。AI 原始方案中的结构/成相判断未被本次软件执行验证，未生成冒充实测的 XRD 谱、产率或相纯度。

跨站及工作空间之外转移使用明确的虚拟转运设备。瓶盖与瓶体在原资产中合并，开盖以设备状态表示；不声称已实现螺纹接触物理。轨迹位姿阈值为 1 mm / 0.1°，仅证明网页终态与下发轨迹一致。最新本机严格物理台账仍为 0/473；本轮不修改该台账。

## 5. 部署与回退

现有机器已经完成安装，不必重装。日常命令：

```bash
cd /home/gaojing/goai_final_lab
./materials.sh status
./materials.sh check
./materials.sh start
```

变更源码后，空闲时构建：

```bash
./materials.sh install
```

该命令校验官方版本、无 ROS、项目包，复用缓存与依赖，构建 OpenLabSite 和 `dist-materials`。首次准备新的项目环境才使用既有 `./install.sh`；不要在原 Isaac Python 中安装依赖。环境锁与 wheel 校验沿用 `configs/deployment.json`、`docs/DEPLOYMENT_0.12.3.md`。

前端构建会立即供网关读取。若修改执行服务 Python，确认没有活动实验再重启自有服务；修改研究后端时也需重启研究服务，然后恢复网关：

```bash
systemctl --user restart goai-materials-execution.service
systemctl --user start goai-materials-gateway.service
# 仅当改了研究后端且没有活动研究时：
systemctl --user restart goai-console.service
systemctl --user start goai-materials-gateway.service
```

## 7. 故障定位

| 现象 | 处理 |
| --- | --- |
| 一直读取布局/Edge 离线 | `./materials.sh check`；确认 `/edge/api/v1/health` 返回 JSON，浏览器不要配置 localhost:8002 |
| 状态桥断开 | 检查 `/execution/health`、`/sim/ws` 与执行租约；页面必须保留才能执行网页轨迹 |
| 多标签不动 | 查看“执行器/观察者”，同一轮只允许一个执行者；关闭旧标签后等待租约交接 |
| 失败后不能提交 | 查看正式任务与 Host 错误决策；服务只对自有 `mwb_` 任务使用 Host 提供的 abort，不解除他人的设备锁 |
| 旧页面缺资源 | 普通刷新加载新构建；主 GLB 按内容哈希缓存，不必清掉所有浏览器存储 |
| 长时间加热看似不动 | 查看实际温度/工艺时间和当前节点，调整倍速；不跳过节点或改短配方 |
| 环境看起来像 Isaac | 几何来自 Isaac USD，当前执行标记为网页轨迹；需 Isaac 物理结果时读取独立的原子动作台账 |

日志：`journalctl --user -u goai-materials-execution.service -u goai-materials-gateway.service`；设备进程日志在 `data/alab/work/device_processes/<process_id>/process.log`；不要把鉴权头、密码或私有启动配置贴进公开日志。

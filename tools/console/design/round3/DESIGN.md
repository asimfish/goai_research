# 多智能体科研文献综述系统｜控制台视觉与交互设计

## 设计主张

这套控制台被定义为一张“可追溯的科研工作台”，而不是传统的运维后台。它既要让研究者快速看懂系统是否可靠，也要在长时间阅读时保持安静。页面以论文页、实验记录卡和审稿批注为视觉隐喻：内容有明确出处，状态有清晰层级，过程可以回看，但不会用炫目的动画和密集图表制造虚假的忙碌感。

设计关键词：可信、克制、清晰、可追溯、有温度的理性。

## 视觉系统

### 配色

| 角色 | 色值 | 用途 |
|---|---:|---|
| 纸张白 | `#F5F3ED` | 全局背景，降低纯白屏幕的刺眼感 |
| 雾白 | `#FBFAF7` | 卡片、抽屉、浮层 |
| 深墨蓝 | `#172B3A` | 主文字、主导航、关键按钮 |
| 石板灰 | `#66737B` | 次级文字、说明、时间戳 |
| 铜绿 | `#2D7468` | 运行中、已通过、主行动反馈 |
| 浅铜绿 | `#DDEBE7` | 选中态和成功态背景 |
| 琥珀 | `#B98032` | 待处理、返工提醒 |
| 浅琥珀 | `#F3E8D5` | 审稿意见、注意事项背景 |
| 朱砂 | `#A94D45` | 终止、失败、阻塞，仅小面积使用 |
| 细线灰 | `#D8DAD6` | 分隔线与表格边界 |

状态不只依赖颜色：同时使用图形、文字和位置表达。通过为实心圆勾、运行中为呼吸点、等待为空心圆、返工为回转箭头、阻塞为方形叹号，便于色觉差异用户辨识。

### 字体层级

中文优先使用“思源黑体 / Noto Sans SC”，数字与英文使用“Inter”，论文标题或成果名称可少量使用“思源宋体 / Noto Serif SC”。

- 页面标题：28 px / 36 px，600；一句话说清当前页面。
- 核心数字：32 px / 40 px，600；只出现在进度、检查和成果三类信息中。
- 分区标题：18 px / 26 px，600。
- 卡片标题：15 px / 22 px，600。
- 正文：14 px / 22 px，400。
- 辅助信息：12 px / 18 px，400。
- 标签：12 px / 18 px，500，避免全大写。

每行正文建议不超过 36 个汉字；大段规程使用 680–760 px 的舒适阅读宽度。

### 间距与圆角

采用 4 px 基础单位，常用间距为 8 / 12 / 16 / 24 / 32 / 48 px。桌面主内容区左右留白 32–48 px，卡片内边距 20–24 px。

- 主面板圆角：16 px。
- 普通卡片圆角：12 px。
- 输入框与按钮圆角：10 px。
- 标签与状态药丸：999 px。
- 分隔主要依靠留白和 1 px 细线，不使用厚重阴影。

阴影仅用于悬浮层：`0 12px 36px rgba(23,43,58,.10)`；常驻卡片使用 1 px 边界或极轻的内阴影。

### 组件风格

- 按钮：主按钮深墨蓝实底；次按钮透明底加细线；危险操作只在终止确认中使用朱砂。
- 卡片：纸张感底色、细边、无装饰性渐变。卡片标题与状态同行，说明文字最多两行。
- 进度：不用复杂甘特图。11 个阶段使用一条可换行的“阶段脊柱”，当前节点放大并显示角色与动词。
- 质量检查：9 项显示为紧凑的 3×3 印章矩阵；首页只显示“7 / 9”，展开才看明细。
- 角色：统一使用抽象的单线科学符号头像，不拟人化；角色色只作 4 px 边标或小圆点。
- 审稿意见：像论文批注，以琥珀色窄边和短标题出现，明确“意见—责任角色—返工阶段”。
- 表格：默认无竖线；标题固定，行高 52–60 px；长字段以两行摘要代替横向滚动。
- 空状态：给出下一步行动，不使用插画填充空间。

### 导航模型

全局采用 88 px 左侧窄轨道，保持稳定的肌肉记忆：

1. 顶部为产品印记“循证台”；
2. 中部依次为“角色、研究、运行、技能、成果”；
3. 底部为服务状态与帮助；
4. 当前项以浅铜绿圆角底和深墨蓝图标标识。

主内容顶部为 64 px 上下文条，只显示当前研究、服务状态和用户入口。任何运行中的页面始终可见“终止运行”，但危险动作保持低视觉权重，点击后需要输入研究题目中的两个词确认。

### 信息密度原则

1. 每屏只回答一个首要问题：首页回答“九个角色如何协作”，实时页回答“现在做到哪、谁在做、有没有风险”。
2. 一屏最多一个主数字组、一个主流程、一个行动区域；细节进入抽屉或次级页。
3. 状态先给自然语言，再给技术证据。例如“引用信息已核对 126 条”，而不是先显示服务日志。
4. 默认展示结果与例外，隐藏重复成功记录；运行日志放在右侧抽屉中按需查看。
5. 同类信息最多三层：摘要、列表、详情。避免卡片套卡片。
6. 空间优先级高于装饰，至少 35% 的视区保留为留白。

## 页面 01｜首页 / 角色总览

### 布局网格

左侧 88 px 导航轨道；主体使用 12 栏网格，左右边距 40 px、栏间距 20 px。顶部 5 栏为产品主张与“发起研究”行动，右侧 7 栏放共享运行账本；下方九个角色沿三条研究链路排布，而非传统九宫格。

### 组件清单

- 产品标题与一句价值说明
- 主按钮“发起一项研究”、次入口“查看最近成果”
- 共享运行账本卡：11 阶段、9 项检查、当前运行摘要
- 三条链路：发现与证据、写作与表达、审阅与创新
- 9 个角色卡：符号头像、角色名、一个动词句、当前状态
- 底部“系统如何交付”三步说明

### 关键交互

悬停角色卡时只高亮它在账本中的输入与输出；点击进入角色详情。账本节点可展开解释阶段目标，但不会在首页显示日志。主按钮打开研究创建页。

## 页面 02｜单个角色详情

### 布局网格

主体为 4 / 8 栏不对称分栏。左栏是角色身份、职责边界、协作对象；右栏是技能规程的文档阅读区。页面底部横跨 8 栏显示该角色最近三次工作记录。

### 组件清单

- 返回角色总览
- 角色符号、名称“引用核查员”、一句职责
- 输入 / 输出 / 不会做什么三项边界
- 上下游角色关系线
- 技能规程目录与正文
- 可折叠的检查准则
- 最近工作记录与“查看证据”入口

### 关键交互

规程目录随阅读位置同步；“查看一次真实执行”在右侧打开证据抽屉。上下游角色可直接切换，不丢失正文阅读位置。

## 页面 03｜发起研究与运行历史

### 布局网格

采用 5 / 7 栏。左侧是一张聚焦的研究创建纸张，右侧是最近运行列表。输入区域刻意只保留一行主题与两个可选项，让启动研究保持轻量。

### 组件清单

- 单行主题输入框与示例占位
- 交付语言分段选择
- 私有语料开关与说明
- 预计流程说明：11 阶段、9 项质量检查、约 35–60 分钟
- 主按钮“开始研究”
- 最近运行列表：题目、时间、状态、阶段、检查、成果
- 状态筛选与搜索

### 关键交互

输入主题后即时显示规范化标题预览；启动前只做必要检查。运行中的项目可直接进入实时观察，已完成项目可打开 PDF，失败项目显示“从中断处继续”。

## 页面 04｜运行实时观察

### 布局网格

这是全套界面的核心。顶部是一条 72 px 运行摘要；主体第一行 8 栏显示 11 阶段的阶段脊柱，4 栏显示 9 项检查；第二行左侧 8 栏只显示当前活跃的 3 个角色，右侧 4 栏显示待处理审稿意见。已完成角色收进一行折叠摘要。

### 组件清单

- 研究题目、已运行时间、低权重“终止运行”
- 自然语言总状态：“正在整理证据与写作结构，未发现阻塞”
- 11 阶段脊柱，当前为“06 结构与写作”
- 9 项质量检查印章矩阵与“7 / 9 已通过”
- 活跃角色卡：角色、正在做的动作、最近产出、用时
- 并行工作连接标记
- 待处理审稿意见 2 条，带责任角色与返工目的地
- “已完成 5 个角色”折叠行
- 事件记录抽屉入口

### 关键交互

阶段脊柱点击后展示该阶段的输入、结果与用时；角色卡点击展开最近三条自然语言动态；检查项点击查看依据。收到审稿意见时，不弹窗打断，而是在右侧卡片中温和出现。终止操作二次确认。

## 页面 05｜技能与 MCP 工具

### 布局网格

左侧 3 栏为技能索引，中间 6 栏为规程正文，右侧 3 栏为服务与工具清单。以“文档阅读器 + 能力目录”组织，不做密集的系统设置页。

### 组件清单

- 9 个角色技能索引及状态
- 当前技能标题、适用范围、关键原则、流程步骤
- 文内锚点目录
- 4 个 MCP 服务卡：文献检索、引用核查、图纸渲染、实验回溯
- 工具清单：名称、用途、可用状态
- 工具搜索与“查看参数”抽屉

### 关键交互

选择技能时正文与相关服务同步过滤；点击工具在抽屉展示中文用途、输入输出与最近调用，不直接暴露冗长原始结构。服务异常时显示影响到哪些角色。

## 页面 06｜成果与历史回看

### 布局网格

左侧 4 栏为历史研究时间线，右侧 8 栏为选中成果的沉浸式预览。预览区模拟论文阅读器，中间为 PDF 首页，右侧窄栏为交付清单与可核验摘要。

### 组件清单

- 历史筛选：全部、已交付、未完成
- 研究时间线卡：题目、完成日期、检查状态、版本
- PDF 预览：首页缩略、页码、缩放、目录
- 成果清单：论文 PDF、TeX 源稿、参考文献、图纸
- 可核验摘要：引用数、图表数、审稿轮次、9 / 9 检查通过
- 行动：“打开 PDF”“下载全部成果”“回放研究过程”

### 关键交互

切换历史项目时右侧无整页刷新；“回放研究过程”以时间轴复现阶段和返工，不播放逐行日志。下载前展示成果清单，确保用户知道将获得什么。

## 动效与可访问性

- 页面切换 180 ms 淡入和 8 px 位移；阶段变化 240 ms；不使用无限旋转加载器。
- 运行中只允许一个呼吸点，周期 1.8 秒，并尊重“减少动态效果”偏好。
- 正文与背景对比度至少 7:1；辅助文字至少 4.5:1。
- 所有状态带文字；所有图标有可见提示；键盘焦点使用 2 px 铜绿描边。
- 最小点击区域 40×40 px；表格和时间线支持键盘顺序导航。

## 实现建议｜Vue 3 + Naive UI

### 全局壳层

使用 `NLayout`、`NLayoutSider` 与 `NLayoutHeader` 搭建稳定框架；导航建议自定义为窄轨道，不直接套用默认 `NMenu` 视觉。颜色、圆角、字号通过 `NConfigProvider` 的 theme overrides 统一管理。图标使用同一套 1.5 px 线性图标，并为九个角色绘制专属但同构的 SVG 符号。

### 页面组件映射

| 页面 | Naive UI 基础组件 | 建议自定义组件 |
|---|---|---|
| 首页 / 角色总览 | `NButton`、`NCard`、`NTag`、`NTooltip` | `LedgerOverview`、`RoleChain`、`RoleGlyph` |
| 角色详情 | `NAnchor`、`NCollapse`、`NDrawer`、`NThing` | `RoleIdentityPanel`、`CollaborationMap`、`ProtocolReader` |
| 发起研究与历史 | `NInput`、`NSegmented`、`NSwitch`、`NDataTable`、`NButton` | `ResearchBrief`、`RunHistoryRow`、`NormalizedTitlePreview` |
| 实时观察 | `NProgress`、`NPopover`、`NDrawer`、`NBadge` | `StageSpine`、`QualityStampGrid`、`ActiveAgentCard`、`ReviewRouteCard` |
| 技能与工具 | `NTabs`、`NAnchor`、`NList`、`NDrawer`、`NInput` | `SkillIndex`、`ToolCatalog`、`ServiceHealthCard` |
| 成果回看 | `NTimeline`、`NButtonGroup`、`NDropdown`、`NDescriptions` | `PaperPreview`、`ArtifactManifest`、`RunReplay` |

### 需要重点自定义的部分

`StageSpine` 不应由步骤条硬改：用 CSS Grid 表示 11 阶段，根据阶段宽度自动换行，并把两段并行工作画成上下双轨。`QualityStampGrid` 用语义化按钮组成 3×3 矩阵，兼顾展开和键盘操作。`PaperPreview` 可接 PDF.js，但外层工具栏与成果清单保持本视觉系统。事件更新使用平滑的局部状态替换，不让整张卡片闪烁。

响应式上，1440 px 以上保持 12 栏；1024–1439 px 降为 8 栏并将审稿意见移到阶段下方；窄于 1024 px 时左侧导航收为底部五项，实时页按“总状态—阶段—检查—角色—意见”单列排列。科研阅读与实时观察以桌面端为优先，不为追求移动端对称而牺牲证据可读性。

## 生图提示词说明

六张界面图均通过内置 image generation 工具生成，统一遵循本文件的配色、排版、角色符号、左侧导航与纸张式组件规范。各图具体提示词以对应页面章节为基础，并明确要求中文文本、16:9 桌面网页、无设备外框、无营销插画、无霓虹渐变、无传统后台大盘风格。

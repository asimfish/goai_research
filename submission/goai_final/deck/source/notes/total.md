# 01_封面

各位评审好，我们是 SAGE-Mat 团队。我们做的是一个面向无机材料合成调研与合成规划的证据约束多智能体系统，一句话概括：一行研究主题进去，可核验的综述、证据链和候选合成路线出来。右侧四个数字概括了这项工作的规模与科学内容：本地文献全文库约三千八百万篇并接入在线检索；九个 Agent 角色和四个自研 MCP 服务；正式案例中对目标相及四个近邻体系的二十八条合成条件做了逐字段比较；对七种目标化合物给出了前驱体路线预测，并提出四个值得探索的新实验方向。

---

# 02_背景与科学gap

先说背景。自动化实验室已经能高通量地做实验，真正的瓶颈不在产能，而在做什么实验、为什么做，这一步仍然靠人读文献。AI for Science 的空缺，是让大模型把文献里的知识抽取、总结、压缩成可执行的假设，再和实验结果、历史文献一起迭代，形成知识闭环。这件事之所以现在重要，有三点：实验产能已经远大于知识吞吐；文献里的成功经验和失败边界是最便宜的实验，跳过它们就是重复别人做过的探索；闭环要能自我纠错，每条假设都必须带可核验的证据。我们的科学空缺就是把散落在文献中的合成知识变成可执行、可追溯、可回写的合成方案，接到实验闭环里。左图实线部分是本系统覆盖的知识侧，虚线是下一环的自动化实验室。

---

# 03_科学问题

具体到科学问题。成功的合成条件和失败的边界都写在文献里，关键是用哪些、怎么找，以及找到之后哪里还有新的科学发现，也就是站在巨人的肩膀上继续前行。科学问题本身也是探索出来的：案例 A 是 LLZO 石榴石固态电解质，由团队在初赛调研中自主探索确定，文献很多，但没有人把它们整理成跨掺杂体系的统一工艺图景；案例 B 是专家推荐的 Ba5Y12Zn[O(SiO4)]8，2024 年首次报道，只有一篇直接合成文献，但近邻体系证据丰富。我们要回答的三个问题是：用哪些文献、怎么找到并核对、新发现在哪里。

---

# 04_系统能力

接下来看系统本身。它的核心设计是把生成像论文的结论改为保存证据与判定过程。认知层是九个用 Markdown 写成的 Agent 角色，由 Codex 执行；确定性层把在线和本地文献检索、题录与作者核对、绘图以及 RECIPE 前驱体预测放进四个 MCP 服务；控制层为每个阶段设定明确完成标准，由程序检查，不由模型自己宣布完成，而且写稿与审稿分离。

---

# 05_Agent交互与数据流

这一页讲 Agent 之间怎么交互。每个 Agent 通过产物文件和共享进度记录交接，记录每一步是否通过、待返工问题与产物版本；上游一变，下游自动重查。文献检索、题录与作者逐条比对、写作与可编辑图纸、RECIPE 候选路线和对抗审稿都沿同一条链流转，审稿问题会回到原阶段返工。这样一来，实验室可以直接接收结构化路线与失败判据，实验结果也能按同样格式回写为证据。

---

# 06_方法路线与闸门

方法路线的关键是，做完了不由模型自己宣布。九道质量关卡全部通过、没有未关闭的严重问题，而且终审有审稿记录，程序才放行交付。正式运行中有四次需要人确认的节点，其中一次是五条作者名不匹配的文献三轮未收敛，交人决定后删除并继续。对抗审稿使用全新上下文，从领域专家、方法严谨派和期刊编辑三个视角提出问题，再沿原路返工。 每道关卡下方标出了负责它的 Agent 编号，和系统能力页一一对应。

---

# 07_RECIPE融入

这一页讲合成方案怎么建模。前驱体交给 AI 预测：RECIPE 把无机逆合成重述为变长前驱体集合的排序问题，先构建高召回候选池，再枚举二到五元集合，用学习到的重排器直接给完整集合排序，每条路线都附分数和校验值，并标注为模型候选、未经实验验证。温度、气氛、助熔剂这些条件则不由模型臆造，而是从结构近邻体系的实验记录中按证据等级类比：固相成相的一千三百度预烧、一千六百度烧成来自 Ba–Y–Si–O 陶瓷系列；助熔生长的 MoO3 助熔、Pt 坩埚、一千一百五十度和每小时两开的慢冷来自同谱系单晶；相场筛查来自粉体研究。同时明确边界：这些数值来自无锌谱系，不能无条件迁移到含锌目标，所以第一步实验是局部相图。左下角是随 checkpoint 提交的基准评测：在两千五百五十八条留出反应上，Combo@1 七十一点八一，比先前最优基线高十一点四个百分点。

# 08_正式案例结果

正式案例是纯主题冷启动，唯一输入是一行关于 Ba 五 Y 十二 Zn 硅酸盐及其近邻化合物合成条件的主题。系统在需要人确认的节点续跑后交出二十页综述，再按材料专家八条意见修订为二十三页正式稿。五十一篇参考文献逐条核对通过，正文有二百一十九次引用，三张图都由同一图源生成可编辑版本，两轮对抗审稿的终审没有遗留问题。右侧的运行事实展示了这些过程都被完整记录。

---

# 09_科学结论与实验方向

在科学结论上，系统给出的不是一份配方，而是文献证据限定的可迁移范围。公开证据只能确认目标相采用开放体系高温溶液法并以单晶衍射鉴定，不足以给出经验证的复现配方；无锌四方谱系提供了助熔生长、固相陶瓷和粉体相场筛查三类可比路线，但具体数值不能无条件迁移。获得单晶不等于建立批量相纯窗口，局部相图才是连接复现与发现的核心实验。基于这些边界，系统提出四个方向，每个方向都配了工艺路线和模型候选前驱体。

---

# 10_LLZO案例

初赛承诺的 LLZO 主题已经端到端跑通：四十六篇文献覆盖六个子主题，逐条核对通过，并整合成十页 A4 综述。模型首选前驱体路线是氧化锆、氧化镧和碳酸锂，与文献一致；次选出现可疑命名，反而说明模型生成、化学式规范化、文献复核和对抗审稿这四步把关非常必要。整轮共有二十一个 Agent 任务和四十九次工具调用，替代材料 Li6PS5Cl、Li3YCl6 和 LATP 的首选路线也都通过文献复核，分别对应高电导冷压、高电压正极侧和低成本空气中操作三种场景。

---

# 11_证据链与可追溯

这一页回到冷启动输入：系统只接收一行主题，也就是 Ba 五 Y 十二 Zn 及其结构相近化合物的合成条件。编排器自动确认范围，四次在需要人确认的节点续跑，组织了二十九批、四十个子任务；文献检索覆盖八个子主题，在线五源加本地全文库得到六十三条候选。引用核对让五十一篇全部通过，写作完成十一章、二百一十九次引用和百分之百整合，绘图把三张视觉参照重建成可编辑图，想法生成调用 RECIPE 三次给出四个实验方向，对抗审稿两轮后首轮七项问题全部关闭、终审零问题。

---

# 12_复现情况与限制

复现与开源的基础，是复用开源的 Codex CLI 作为 Agent 宿主，九个角色都写成可读的 Markdown 说明。我们自主设计并开源四个 MCP 服务，覆盖文献检索、引用核对、绘图和 RECIPE 前驱体预测；知识库由部分公开的文献全文库和在线检索组成，被引文献中有二十一篇全文进入公开知识库。绘图工具让一份图源同时生成论文图和 draw.io 可编辑图，整个仓库按 MIT 协议开源，支持一键安装、用一到两分钟完成冒烟测试，并用同一主题重跑整条流水线。需要诚实说明的是，目标相只有一篇直接报道，大模型步骤不可逐字复现，所以我们以所有质量关卡通过作为复现判据。

---

# 13_开源与结论

最后是应用价值。这套系统真正改变的，是把"该不该相信这条结论"变成一个可以点开 DOI 和原文段落回答的问题。对材料研究者，一次运行替代数周的文献梳理，五十一篇文献逐条核对，二十八条合成条件逐字段比较，前人结论汇总之后可以直接进入课题设计。对自动化实验室，我们交付的是可执行的方案而不是一段总结：前驱体、条件、表征和失败判据都是结构化对象，实验结果同格式回写为证据，触发新一轮迭代，需要人确认的节点保留在回路中。对只有一篇报道的新化合物，系统也能从近邻体系推断可迁移的边界，给出四个实验方向和七种化合物的前驱体候选，把探索预算花在最有发现价值的地方。下一步我们会接入跨模型审稿，对四个方向开展合成实验并回写证据，整个仓库以 MIT 协议开源。感谢各位评审。

# 01_封面

各位评审好，我们是 SAGE-Mat 团队。我们做的是一个面向无机材料合成调研与合成规划的证据约束多智能体系统，一行研究主题进去，可核验的综述、证据链和候选合成路线出来。右侧四个数字概括了复赛成果：本地文献全文库约三千七百五十七万篇，并接入在线五源检索；九个 Agent 角色、四个自研 MCP 服务和二十五个工具协同工作；正式报告五十一篇参考文献逐条核对通过，最后形成二十三页正式综述。

---

# 02_科学问题

我们先说明要解决的科学问题。无机材料的合成条件散落在论文实验部分，研究者真正需要知道的是文献能限定什么、哪些近邻条件可以迁移、哪些迁移不成立，以及下一步做什么实验最有发现价值。我们用两个案例覆盖两种情形：左边的 LLZO 是团队在初赛调研中自主探索确定的问题，右边的 Ba 五 Y 十二 Zn 硅酸盐是材料领域专家推荐的问题。也就是说，科学问题本身也是探索出来的；难点还包括检索会混入综述和参考文献列表、未检出不等于未研究，以及温度和气氛只有在实验语境一致时才能比较。

---

# 03_系统能力

接下来看系统本身。它的核心设计是把生成像论文的结论改为保存证据与判定过程。认知层是九个用 Markdown 写成的 Agent 角色，由 Codex 执行；确定性层把在线和本地文献检索、题录与作者核对、绘图以及 RECIPE 前驱体预测放进四个 MCP 服务；控制层为每个阶段设定明确完成标准，由程序检查，不由模型自己宣布完成，而且写稿与审稿分离。

---

# 04_Agent交互与数据流

这一页讲 Agent 之间怎么交互。每个 Agent 通过产物文件和共享进度记录交接，记录每一步是否通过、待返工问题与产物版本；上游一变，下游自动重查。文献检索、题录与作者逐条比对、写作与可编辑图纸、RECIPE 候选路线和对抗审稿都沿同一条链流转，审稿问题会回到原阶段返工。这样一来，实验室可以直接接收结构化路线与失败判据，实验结果也能按同样格式回写为证据。

---

# 05_方法路线与闸门

方法路线的关键是，做完了不由模型自己宣布。九道质量关卡全部通过、没有未关闭的严重问题，而且终审有审稿记录，程序才放行交付。正式运行中有四次需要人确认的节点，其中一次是五条作者名不匹配的文献三轮未收敛，交人决定后删除并继续。对抗审稿使用全新上下文，从领域专家、方法严谨派和期刊编辑三个视角提出问题，再沿原路返工。

---

# 06_RECIPE融入

预测部分来自团队投稿 NeurIPS 二零二六的 RECIPE 工作。它先用 formula-token Transformer 构建高召回候选池，再做化学硬过滤和二至五元组合枚举，最后用目标条件化的集合重排器直接对完整集合排序。它以 MCP 工具进入想法生成环节，每条路线都标注为模型候选、未经实验验证，并附阶段分数和 checkpoint 哈希供核对。正式报告中对锌、镁、钴三个目标各调用了一次。

---

# 07_正式案例结果

正式案例是纯主题冷启动，唯一输入是一行关于 Ba 五 Y 十二 Zn 硅酸盐及其近邻化合物合成条件的主题。系统在需要人确认的节点续跑后交出二十页综述，再按材料专家八条意见修订为二十三页正式稿。五十一篇参考文献逐条核对通过，正文有二百一十九次引用，三张图都由同一图源生成可编辑版本，两轮对抗审稿的终审没有遗留问题。右侧的运行事实展示了这些过程都被完整记录。

---

# 08_科学结论与实验方向

在科学结论上，系统给出的不是一份配方，而是文献证据限定的可迁移范围。公开证据只能确认目标相采用开放体系高温溶液法并以单晶衍射鉴定，不足以给出经验证的复现配方；无锌四方谱系提供了助熔生长、固相陶瓷和粉体相场筛查三类可比路线，但具体数值不能无条件迁移。获得单晶不等于建立批量相纯窗口，局部相图才是连接复现与发现的核心实验。基于这些边界，系统提出四个方向，每个方向都配了工艺路线和模型候选前驱体。

---

# 09_LLZO案例

初赛承诺的 LLZO 主题已经端到端跑通：四十六篇文献覆盖六个子主题，逐条核对通过，并整合成十页 A4 综述。模型首选前驱体路线是氧化锆、氧化镧和碳酸锂，与文献一致；次选出现可疑命名，反而说明模型生成、化学式规范化、文献复核和对抗审稿这四步把关非常必要。整轮共有二十一个 Agent 任务和四十九次工具调用，替代材料 Li6PS5Cl、Li3YCl6 和 LATP 的首选路线也都通过文献复核，分别对应高电导冷压、高电压正极侧和低成本空气中操作三种场景。

---

# 10_基准指标

这是 RECIPE 融入部分的基准结果。两千五百五十八条留出反应上，Combo@1 达到百分之七十一点八一，比先前最优的 Retrieval-Retro 高十一点四个百分点；Combo@20 是百分之八十九点二一，Combo MRR 是百分之七十七点四八，落在论文三种子均值的误差区间内。同枚举下只用概率乘积排序的对照只有百分之十一点六五，说明增益来自学习到的集合级排序，而不是候选枚举或过滤本身。提交包还带有 CPU dry run，确保模型可以加载并完成预测。

---

# 11_证据链与可追溯

这一页回到冷启动输入：系统只接收一行主题，也就是 Ba 五 Y 十二 Zn 及其结构相近化合物的合成条件。编排器自动确认范围，四次在需要人确认的节点续跑，组织了二十九批、四十个子任务；文献检索覆盖八个子主题，在线五源加本地全文库得到六十三条候选。引用核对让五十一篇全部通过，写作完成十一章、二百一十九次引用和百分之百整合，绘图把三张视觉参照重建成可编辑图，想法生成调用 RECIPE 三次给出四个实验方向，对抗审稿两轮后首轮七项问题全部关闭、终审零问题。

---

# 12_复现情况与限制

复现与开源的基础，是复用开源的 Codex CLI 作为 Agent 宿主，九个角色都写成可读的 Markdown 说明。我们自主设计并开源四个 MCP 服务，覆盖文献检索、引用核对、绘图和 RECIPE 前驱体预测；知识库由部分公开的文献全文库和在线检索组成，被引文献中有二十一篇全文进入公开知识库。绘图工具让一份图源同时生成论文图和 draw.io 可编辑图，整个仓库按 MIT 协议开源，支持一键安装、用一到两分钟完成冒烟测试，并用同一主题重跑整条流水线。需要诚实说明的是，目标相只有一篇直接报道，大模型步骤不可逐字复现，所以我们以所有质量关卡通过作为复现判据。

---

# 13_开源与结论

最后总结，这套系统真正改变的，是把该不该相信一条结论变成一个可以点开 DOI 和原文段落回答的问题。全部代码、提示词、配置、模型 checkpoint、轨迹和证据包都以 MIT 协议开源，仓库地址是 asimfish/goai_research。下一步我们会接入跨模型审稿，对四个方向开展合成实验，把结果回写为证据，并扩展温度、气氛和助熔剂条件预测器。感谢各位评审。

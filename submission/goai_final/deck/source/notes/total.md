# 01_封面

各位评审好，我们是 SAGE-Mat 团队。我们做的是一个面向无机材料合成调研与合成规划的证据约束多智能体系统，它的目标可以用一句话概括：一行研究主题进去，可核验的综述、证据链和候选合成路线出来。右侧四个数字是复赛阶段的核心结果：正式报告五十一篇文献全部通过三轴核验，一百条结论逐条可追溯，前驱体预测模型在两千五百五十八条留出反应上完成了独立重算，最终形成一份二十三页的正式综述。

---

# 02_科学问题

我们先说明要解决的科学问题。无机材料的合成条件散落在成千上万篇论文的实验部分，对于一个只有单篇报道的新化合物，研究者真正需要知道的是：文献能限定什么、哪些近邻体系的条件可以迁移、哪些迁移并不成立，以及下一步做什么实验最有发现价值。我们用两个案例覆盖两种极端情形：正式案例 BYZSO 是文献稀缺但近邻丰富，只有一篇直接合成报道；初赛承诺的 LLZO 则是文献丰富但条件不可比。这个问题难在检索会混入综述与参考文献列表，未检出并不等于未研究，而且温度、气氛和致密度只有在实验语境一致时才能比较。

---

# 03_系统能力

接下来看系统本身。它的核心设计是把"生成像论文的结论"改为"保存证据与判定过程"。系统分三层：认知层是九个以 Markdown 写成的 agent 技能，由 Codex 宿主执行，这也是我们提交的全部提示词；确定性层是四个可离线测试的 MCP server，覆盖文献检索与本地全文库、引用三轴核验、可编辑图纸渲染和两阶段前驱体预测，共二十五个工具；控制层是账本驱动的回环，九个出口闸门由代码判定完成，审稿人不改稿，执行者不自判。

---

# 04_方法路线与闸门

方法路线的关键是"完成"不由模型自报。check-done 只在九个闸门全部落账、没有失败项、没有未关闭的严重问题，并且终审通过指向真实存在的审稿记录时才会退出零。正式运行中系统在四个人工停点上停下并以同一主题续跑，其中一次是五条作者名不匹配三轮未收敛后升级人工处理。对抗审稿使用全新上下文，从领域专家、方法严谨派和期刊编辑三个视角产出结构化问题，并路由回属主阶段返工。

---

# 05_RECIPE融入

预测部分来自团队投稿 NeurIPS 2026 的 RECIPE 工作。它把无机逆合成重新表述为变长前驱体集合的排序问题：第一阶段用 formula-token Transformer 构建高召回候选池；第二阶段做化学硬过滤并枚举二到五元组合，典型规模约四千九百个集合；第三阶段用目标条件化的集合重排器直接对完整集合排序。它以 MCP 工具的形式进入想法生成环节，skill 层硬性规定输出只能标注为模型候选、待实验验证，并附带各阶段分数和 checkpoint 哈希供审稿人核对。正式报告中对锌、镁、钴三个目标各调用了一次。

---

# 06_正式案例结果

正式案例是纯主题冷启动。系统的唯一输入是一行主题，经过四个人工停点续跑后交出二十页综述，再按材料专家八条意见修订为二十三页正式稿。五十一篇文献全部通过三轴核验，正文两百一十九次引用、整合率百分之百，三张图均为 figspec 同源的可编辑图，两轮对抗审稿的终审没有任何遗留问题。下方是正式报告的研究路线图，右侧是全部留痕的运行事实。

# 07_科学结论与实验方向

在科学结论上，系统给出的不是一份配方，而是文献证据限定的可迁移范围。公开证据只能确认目标相采用开放体系高温溶液法并以单晶衍射鉴定，不足以给出经验证的复现配方；无锌四方谱系提供了助熔生长、固相陶瓷和粉体相场筛查三类可比路线，但具体数值不能无条件迁移；获得单晶不等于建立批量相纯窗口，局部相图才是连接复现与发现的核心实验。据此系统提出四个方向，每个方向都配了工艺路线和模型候选前驱体。

---

# 08_LLZO案例

初赛承诺的 LLZO 主题在复赛阶段作为诊断轮跑通了端到端：四十六篇文献六个子主题覆盖、全部核验通过、十页综述，模型给出的首选前驱体路线与文献一致，而第二名之后出现了可疑命名，这正是我们保留模型生成、规范化、文献复核、审稿这一闸门的原因。这一轮暴露了十一类集成失效模式，全部留痕并修复，包括冷启动首次尝试暴露的单闸门即宣告完成的漏洞。

---

# 09_基准指标

这是 RECIPE 融入部分的独立复核。我们用与 MCP 工具完全相同的推理代码，在两千五百五十八条留出测试反应上重算：Combo@1 为七十一点八一，比先前最优基线 Retrieval-Retro 高十一点四个百分点；Combo@20 为八十九点二一，Combo MRR 为七十七点四八。结果与 checkpoint 自带汇总逐位一致，并落在论文三种子均值的误差区间内。同枚举下仅用概率乘积排序的对照只有十一点六五，说明增益来自学习到的集合级排序，而不是候选枚举或过滤本身。

# 10_证据链与可追溯

复赛评审强调可追溯，我们的每条结论都能沿同一条链回到提交包中的具体文件：代码版本、配置、数据、日志与轨迹、结果文件。以第十二条结论为例，它对应的引用键、DOI、三轴核验结果、写作子任务的事件流和最终章节都可以逐一打开。运行统计、分目录存放的构筑与运行阶段 Agent 轨迹，以及私有全文库的数据边界，也都在这一页如实列出。

---

# 11_复现情况与限制

复现方面，干净环境下一键安装后运行冒烟测试，一到两分钟内无网络、无大模型即可验证环境、四个 MCP server、五十六项离线测试、公开知识库、结论与证据链以及图纸渲染；基准指标可以逐位复现；核心流程用同一主题、同一模型和推理强度重跑，以闸门一致作为复现判据。我们也如实披露限制：目标相只有一篇直接报道，公开知识库只覆盖被引文献中二十一篇全文，终审是同家族模型的复审，正式稿包含有记录的专家反馈修订。

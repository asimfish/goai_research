## 2. 结构护栏

四份全文的共同组织单元不是“论文 A、论文 B、论文 C”的逐篇罗列，而是先建立比较问题或作用机制，再按互斥类别放入代表证据，最后回到适用条件和边界。未来写作应遵循以下护栏：

1. 开头用三步完成定位：说明问题为何难，指出现有证据或方法的缺口，明确本综述将如何组织比较；不要以宽泛领域史堆砌篇幅。
2. 背景只保留后文比较必需的定义、结构单元和过程变量。每个背景概念必须在后续比较、表格或判断标准中被调用。
3. 方法/路线类内容先写“变量为何影响结果”，再列代表实例；实例不独立成资料卡式段落。
4. 每个分类单元都用同一组比较字段收束，使读者能横向比较，而不是只获得按年份排列的事实。
5. 讨论段必须区分一致证据、相互矛盾的结果、证据空白和不可迁移边界。结尾综合已建立的比较，不重复摘要式罗列。

SB18 与 SB24 作为主要体裁参照：前者擅长把合成介质的物理化学逻辑连接到实例，后者擅长把机理、仪器、验证和放大约束放在同一论证链。SB15 可借鉴紧凑分类与结构—结果连接；SB25 只借鉴简短机制图和实例节奏，不采用其缺少对照表、批判综合较弱的短篇结构。

## 3. 段落与句式护栏

建议段落采用“判断句—证据比较—限定句—过渡句”的四拍结构：首句回答本段的问题；中间用两到数条 citation-bound 证据做同字段比较；随后指出证据等级、条件或不确定性；末句说明该判断如何引向下一比较维度。事实性句子不允许把引用集中甩在段尾。

可复用的是修辞功能，不是范文原句：

- 范围句：明确纳入什么以及为什么排除什么。
- 对比句：在同一变量上给出两类路线或两组结果的差异。
- 因果句：只有摘要/原文直接给出机制证据时使用“导致/决定”；其余改为“伴随/与……一致/提示”。
- 限定句：用 D0、D1、N1、P1 或“当前证据包未报告”明确降权原因。
- 综合句：总结跨论文一致性，不用单篇结果代表整类体系。

避免三类句式：一是连续使用“已有大量研究”“众所周知”等无证据开场；二是用“similar/analogous”越过结构和工艺证据距离；三是用“最佳、优化、成功”却不同时给出比较基准、相纯度终点或适用条件。

## 4. 引用与证据密度护栏

四篇范文分别使用约 32、75、201 和 260 条参考文献，长综述通过高密度 citation calls 支撑机制、实例和边界，而不是仅在段尾给一组综述性引文。结合 writer skill 的硬线，未来正文采用以下量化护栏：

| 项目 | 护栏 |
|---|---|
| citation-call 密度 | 每千词至少 8 次；表格单元格和高信息密度段落另行逐 claim 绑定 |
| 库内整合率 | 至少 90%；52 个已过闸 key 的正文目标不少于 47 个 |
| 证据强度 | 摘要/允许笔记直接支持才标 strong；只有题名、书目信息或间接分类依据时标 weak |
| 近邻使用 | N1/P1 只能支撑结构或工艺类比，不得承担 D0 目标相合成/复现 claim |
| 引用位置 | 紧跟可核查事实；同一句含多个独立事实时拆句或分别绑定 |

“每千词至少 8 次”用于后续 `bib_guard`，不是从四份 PDF 的粗糙页数比机械换算而来；PDF 多栏抽取和参考文献页会扭曲精确词数。阶段二的候选量与近三年比例另由 `bank_check` 留痕并按 52 条受限引用池显式适配。

## 5. 表格与图形护栏

四张内部范图显示三种有效视觉语法：结构视图与性能曲线并置（SB15）、过程示意与多尺度显微/晶向证据串联（SB18）、共享色标的并列机制比较（SB24）；SB25 的单色机械过程图说明复杂机理可用少量标签交代。只吸收这些语法，不复制图面内容。

1. 一张图只承担一条主线。结构、过程、验证结果并置时必须共享编号、方向或变量编码，避免拼贴式“图鉴”。
2. 同类面板共享颜色、尺度和标注位置；颜色只编码稳定语义，不兼作装饰。
3. 结构近邻图必须显式标证据层级，视觉相似不能暗示同构或 D0 身份。
4. 条件比较优先用统一字段表；空缺写“未报告/NA”，禁止从近邻补值。表格需同时呈现输入条件、产物终点、鉴定方法和迁移等级。
5. caption 先给图的判断目的，再解释编码和证据边界；正文解释主线，不复述 caption。
6. 最终交付图仍须遵守仓库铁律，以 figspec 同源产出 SVG 与 drawio；本阶段不生成或规划具体论文图。

## 6. 版式与编辑护栏

- 标题采用 2–6 词信息性名词短语；层级表达对象—分支—细项，细项留在 run-in paragraph，避免把枚举抬成编号小节。
- 短枚举采用段内 `(i)…; (ii)…; (iii)…`；显示列表只用于每项至少一句完整判断的内容。
- 对比表字段名保持短而可测；数值与单位统一，脚注只解释边界和缺失，不承载核心结论。
- 图、表和正文中的术语、相式、证据等级保持同名；首次定义后不随意换同义词。
- 结论强度与 citation bank 的 strong/weak 一致。精修只能提高可读性，不能抹去相矛盾、缺字段或负结果。

## 8. 本轮材料化学定向写作校正（2026-09-02）

本轮进一步以目标论文及 Ba--Y--Si--O 原始研究的行文组织作定向校正：`ababaikeri2024ba5y12zn` 用“研究对象--结构新颖性--实验获得--结构/性质终点”建立目标；`wierzbickawieczorek2017high` 以变量控制和跨批次结论组织 151 组实验；`gulay2024navigation` 用“相空间问题--迭代组成选择--多模态结构验证--可推广发现流程”连接相图与新相发现；`yamane2024synthesis` / `yamane2024microstructure` 把单晶身份、非整比组成和陶瓷副相分开讨论。由此对正文执行四项改写：

1. 引言从目标材料和科学问题起笔，不再用检索日期或工具流程代替研究背景。
2. 相近体系按“已经发现什么--对目标问题有什么约束--不能外推什么”成段综合，不按论文逐条罗列。
3. 结果部分先给跨实验结论，再给证据和限定；内部工作流术语只保留在方法或审计记录中。
4. 未来方向按可区分的科学假设组织，每项同时给前驱体、工艺起点、验证终点和失败解释；模型结果明确标为候选，不写成化学事实。

该校正只影响论证和语言，不改变任何文献的证据等级。

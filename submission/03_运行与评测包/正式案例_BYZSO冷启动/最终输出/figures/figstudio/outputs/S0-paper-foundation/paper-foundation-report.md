## S0-01 论文深读（与图相关的骨架）
1. **对象与主张**：目标相 Ba5Y12Zn[O(SiO4)]8 仅有一篇直接报道（高温溶液 + 单晶 XRD，§1、§3）；批量成相区、投料、热史未知（记 NA）。综述主张：不拼“最佳配方”，而是分级文献、统一比较实验项目、设计可区分假设的实验（§1、§3、§8）。
2. **文献分级（fig01 骨架，§3.1）**：五类来源 —— 目标化合物直接报道（1 篇）/ 无 Zn 的同类 Ba–Y 四方硅酸盐 / 结构相关化合物 / 工艺参照研究 / 非相关资料。前四类在“相同实验项目”下整理（原料、热史、气氛、容器、冷却、产物表征），各类可回答的问题不同：直接复现只依据直接报道；谱系内可比相图与结构；结构相关与工艺参照只借方法与变量结构；非相关资料只划定范围。关键警示：近邻条件 ≠ 目标相已验证配方，数值不得无条件迁移。
3. **路线—条件—表征（fig02 骨架，§4、§5、§6）**：五条路线（外加助熔、自熔/熔体、固相陶瓷、机械化学预活化、Czochralski）各自的记录项目不同但在统一实验记录（配比与原料、温度—时间与气氛、坩埚与助熔/矿化剂、冷却/生长/分离与失重）下并列；四类互补表征回答不同问题（单晶结构→结构身份与位点占据；PXRD/Rietveld→批量相纯与杂相；成分与污染→名义—局域—体平均；高温稳定性→原位高温 ≠ 冷却回收）。连线只表示“条件项对应表征结论”，不表示因果。Czochralski 仅作工艺参照。
4. **研究路线（fig03 骨架，§1.2、§8）**：文献依据（Ba–Y–Si–O 谱系 / Ba–Zn–Si–O 结构近邻 / Y–Si–O 工艺参照）→ 结构假设（局部组成网格、Zn–Y–氧计量耦合、竞争相与玻璃区）→ 模型筛选的前驱体（BaCO3 + Y2O3 + SiO2 + ZnO/MgO/Co3O4；模型排序 ≠ 验证）→ 并行两支：固相成相（分段煅烧→复磨→退火；批量相区与相纯度）与高温溶液长晶（助熔→保温→慢冷；单晶结构与液相选择性）→ 结果反馈（PXRD/Rietveld、SCXRD、EDS/EPMA/ICP、高温相与冷却产物）→ 反馈更新结构假设。三个待答问题：稳定相区还是液相选择性晶体？Zn 是否进入无 Zn 谱系并与氧计量耦合？实际组成与结构信号如何对应？

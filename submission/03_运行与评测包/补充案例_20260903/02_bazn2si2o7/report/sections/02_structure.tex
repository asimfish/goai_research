\section{结构基础与多晶型}

\subsection{低温相与高温相}

BaZn$_2$Si$_2$O$_7$ 在约 280--300~$^\circ$C 附近发生结构转变；低温相的 ZnO$_4$ 链具有较强方向性，高温相则通过四面体转动和链间角度调整释放热应变 \cite{lin1999phase,thieme2015ba1}。高温 X 射线衍射和膨胀测量显示，两种结构的热膨胀张量差异远大于常规烧结误差，说明相变本身是相控制的首要变量 \cite{kerstan2012thermal,thieme2016very}。

公开结构数据将低温 BaZn$_2$Si$_2$O$_7$ 归入正交 Cmc2$_1$，Ba$^{2+}$ 处于五配位，Zn$^{2+}$ 和 Si$^{4+}$ 均为四面体配位；ZnO$_4$ 与 SiO$_4$ 通过角共享形成三维网络 \cite{available2020materials}。这些配位数字适合用于结构类比的第一层筛选，但数据库条目不是高温原位结构证据，不能替代原始衍射精修。

\subsection{结构判据}

用于比较 Ba$_5$Y$_{12}$Zn[O(SiO$_4$)]$_8$ 的判据可分四层：硅酸根是否保持孤立四面体；Zn 是否保持四配位并形成可追踪的角共享链；Ba/Y 多面体是否提供相近的连接维度；最后才比较空间群和晶胞参数。前两层来自 BaZn$_2$Si$_2$O$_7$ 的直接结构证据 \cite{lin1999phase,available2020materials}，后两层需要 Ba$_5$Y$_{12}$Zn[O(SiO$_4$)]$_8$ 的单晶或高分辨粉末数据，目前尚未获得。
